# STATUS — Translated Editions Handbook

Last updated: 2026-11-06

## What was built

A self-contained, beginner-friendly author manual on **selling translated editions of books**, by Dylan Asdale / Asdale Dynamics, LLC. Everything is local-first: static files, no build dependencies beyond Python 3's standard library, no JavaScript required to read the site, no network calls at read time.

### Static HTML site (`site/`)

- Generated by `build.py` from `docs/` — never hand-edited.
- `index.html`: landing page with 10 chapter cards and a "what you'll learn" summary.
- One HTML page per chapter with shared masthead, chapter nav (current page highlighted), prev/next pager, and footer credit.
- `style.css`: warm, readable, mobile-friendly; no external fonts, no CDN, no trackers, no scripts.
- **Distinction guardrails included in the content**: this handbook stays inside its own lane (translated editions only), explicitly pointing readers to the neighboring handbooks for everyday personal AI translation and for general wide-store distribution.

### Tooling

- `build.py` — markdown → static site generator (stdlib only; handles headings, paragraphs, bold/italic/code spans, links with `.md`→`.html` resolution, ul/ol, tables, blockquotes, fenced code).
- `tests/test_build.py` — 38 unit/integration tests (stdlib `unittest`).
- `README.md`, `LICENSE` (MIT, Copyright (c) 2026 Asdale Dynamics, LLC), `STATUS.md` (this file).

## How to run it

```bash
# Build the site from docs/
python3 build.py

# Read the site locally
python3 -m http.server 8000 --directory site
# then open http://localhost:8000

# Run the test suite (38 tests)
python3 -m unittest discover -s tests -v
```

Requires Python 3.8+. Everything runs offline. Output `site/` regenerates fully on every build, so edit `docs/` and rebuild, never `site/`.

## Known gaps / honest limits

1. **Market numbers are 2026 snapshots, not gospel.** Reviewer per-1,000-word rates, Amazon royalty price bands, and ad CPC ranges are realistic ballparks for planning, not current-price guarantees; the text itself says so and points readers to re-verify at publish time.
2. **Legal disclaimer covers the rights chapter.** Chapter 2 explains rights concepts in plain English but is explicitly not legal advice; a review by counsel is recommended before signing anything substantial (the text says this too).
3. **The generator covers only the Markdown subset this handbook uses.** Practical for this project, but it does not attempt full CommonMark (no nested block constructs, no images, no heading-linked auto-anchors beyond slugged `id`s). Adding new syntax makes `build.py` grow accordingly.
4. **The site has no search, print stylesheet, or RSS.** Letter-and-chapter nav is deliberately minimal for a first release; all three would be small followups if the site grows.
5. **Amazon's translation program section is program-status-agnostic.** That program has opened/closed by invitation historically; the handbook tells readers how to evaluate it whenever it's open, rather than checking its status for them.
6. **All example rates are USD.** Non-US readers must convert; noted in the budget chapter but not localized per currency.
